# AgentSkills Format Reference

Based on analysis of https://github.com/agentskills/agentskills/tree/main/skills-ref

## SkillProperties Model

```python
@dataclass
class SkillProperties:
    """Properties parsed from a skill's SKILL.md frontmatter."""
    
    # Required fields
    name: str                    # Skill name in kebab-case
    description: str             # What the skill does and when to use it
    
    # Optional fields
    license: Optional[str] = None
    compatibility: Optional[str] = None
    allowed_tools: Optional[str] = None
    metadata: dict[str, str] = field(default_factory=dict)
```

## Skill Directory Structure

Each skill is a directory containing:
```
my-skill/
├── SKILL.md          # Main skill file with frontmatter + instructions
├── resources/        # Optional: supporting files, examples, data
└── tests/            # Optional: test cases for the skill
```

## SKILL.md Format

```markdown
---
name: my-skill-name
description: What this skill does and when the model should use it
license: Apache-2.0
compatibility: Claude 3.5+
allowed_tools: browser, code_execution
metadata:
  author: Your Name
  version: 1.0.0
  category: meta-analysis
---

# Skill Title

## Overview
Brief description of what this skill teaches or enables.

## Instructions
Detailed instructions for the AI agent on how to use this skill.

## Examples
Concrete examples of skill usage.

## Assessment
How to verify skill mastery.
```

## XML Prompt Format

Generated by `skills-ref to-prompt`:

```xml
<available_skills>
<skill>
<name>my-skill</name>
<description>What this skill does and when to use it</description>
<location>/path/to/my-skill/SKILL.md</location>
</skill>
</available_skills>
```

## CLI Commands

```bash
# Validate a skill
skills-ref validate path/to/skill

# Read skill properties (outputs JSON)
skills-ref read-properties path/to/skill

# Generate <available_skills> XML for agent prompts
skills-ref to-prompt path/to/skill-a path/to/skill-b
```

## Python API

```python
from pathlib import Path
from skills_ref import validate, read_properties, to_prompt

# Validate a skill directory
problems = validate(Path("my-skill"))

# Read skill properties
props = read_properties(Path("my-skill"))

# Generate prompt for available skills
prompt = to_prompt([Path("skill-a"), Path("skill-b")])
```
